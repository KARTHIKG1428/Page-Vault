# PageVault – Peer-to-Peer Textbook Exchange Platform

PageVault is a digital library platform designed to help college students buy, borrow, lend, and exchange academic textbooks easily.

## Features
- Book listing and catalog management
- Search books by title, author, and course code
- Borrow and return request management
- Book availability status
- Due-date reminders and countdowns
- My Books dashboard
- Borrowing history
- Responsive user interface

## Technologies Used
- HTML
- CSS
- JavaScript
- React / Node.js (where implemented)
- Database storage

## Project Objective
To create a campus-wide textbook-sharing platform that reduces textbook costs and makes academic resources easily accessible to students.
